# Pontaj — Program de lucru

Aplicație web (un singur fișier HTML) pentru foaia lunară de program de lucru: ture de zi (Z) și noapte (N) de 12 ore, concediu de odihnă (CO) și de boală (CB), calcul normă lunară (zile lucrătoare × 8h, fără sărbători legale), generare automată a programului, export Excel și printare.

Datele se salvează doar local în browser (localStorage). Numele din exemplu sunt fictive.

Acces: https://calin555.github.io/pontaj/
